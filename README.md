# 🍴 Culinary Journey

> Receitas do mundo, sabores sem fronteiras.

Blog de gastronomia desenvolvido como trabalho acadêmico de Frontend, com foco em
**HTML semântico** e **CSS** puro (sem frameworks). O site reúne receitas, um panorama
das cozinhas de diferentes países e indicações de restaurantes meramente ficticios.

---

## 📑 Sobre o projeto

O **Culinary Journey** é um blog dedicado a quem gosta de cozinhar e comer bem. A proposta
é unir o prazer da boa mesa ao conhecimento sobre ingredientes, técnicas e a cultura por
trás de cada prato, organizado em uma navegação simples e consistente.

## 🗂️ Páginas

| Página            | Arquivo                  | Conteúdo                                              |
| ----------------- | ------------------------ | ----------------------------------------------------- |
| Home              | `index.html`             | Apresentação do blog e conteúdos em destaque          |
| Receitas          | `receitas.html`          | Receitas com tempo de preparo, dificuldade e porções  |
| Cozinhas do Mundo | `cozinhas-do-mundo.html` | Culinárias típicas de diferentes países               |
| Restaurantes      | `restaurantes.html`      | Indicações com nota, tipo de cozinha e faixa de preço |
| Contatos          | `contatos.html`          | Formulário e formas de contato                        |

## ✨ Funcionalidades e destaques

- Estrutura **semântica** completa (`header`, `nav`, `main`, `article`, `aside`, `footer`)
- Menu de navegação fixo e idêntico em todas as páginas
- Imagens dos destaques na Home funcionam como **links** para as respectivas seções
- Botão **"Favoritar"** nas receitas feito apenas com CSS (sem JavaScript)
- Bandeiras dos países na seção de cozinhas do mundo
- Etiquetas com ícones (tempo, dificuldade, preço, ambiente)
- Layout **responsivo**, adaptado para celular e desktop
- Paleta de cores quente e identidade visual própria

## 🛠️ Tecnologias

- **HTML5**
- **CSS3** (Flexbox, gradientes, variáveis CSS e media queries)

## ▶️ Como executar

Não é necessário instalar nada. Basta clonar o repositório e abrir a página inicial
no navegador:

```bash
git clone https://github.com/vinicciusbarbosa/site-gastronomia.git
cd site-gastronomia
```

Em seguida, abra o arquivo `index.html` no navegador (duplo clique) e navegue pelo menu.
